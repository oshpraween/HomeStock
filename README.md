# HOMESTOCK

**Smart Inventory Management for Your Home**

---

## 📌 Overview

HomeStock is a web-based application designed to help households efficiently manage their home inventory, groceries, and essentials. It reduces waste, prevents shortages, and ensures timely restocking.

---

## 🚀 Features & Benefits

- Inventory Tracking with Expiry Management
- Low-Stock Alerts & Expiry Notifications
- Secure User Authentication
- Auto-Generated Shopping Lists
- Email & Voice Alert Integration

---

## 🧩 Main Functions

- **Inventory Management**
- **User Authentication**
- **Alerts & Notifications**
- **Shopping List & Restocking**

---

## ⚙️ Tech Stack

- Frontend: React / HTML / CSS
- Backend: Node.js / Express.js
- Database: MongoDB
- Authentication: JWT
- Notifications: Email Services

# HOMESTOCK – Team Branches & Responsibilities

Each module is developed in its own Git branch under a feature-based branching strategy.

---



**Module:** Inventory Management  
**Branch:** `feature/perera`  
**Responsibilities:**
- Add, view, update, delete inventory items
- Track expiry dates
- Detect low-stock items

---

**Branch:** `feature/waduge`  
**Responsibilities:**
- User registration & login

- User role management

---


**Module:** Alerts & Notifications  
**Branch:** `feature/ranasinghe`  
**Responsibilities:**
